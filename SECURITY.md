# Security Policy

## Supported version

Only the version currently deployed from the `main` branch is supported.

## Reporting a vulnerability

Do not open a public issue containing sensitive security information.

Report a suspected vulnerability privately to:

anass.famame@gmail.com

Include:

- the affected page or file;
- a clear description;
- safe reproduction steps;
- the potential impact;
- a proposed remediation when possible.

Never include real credentials, private infrastructure addresses,
customer data or confidential company information.
